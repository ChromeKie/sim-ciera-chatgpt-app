Sim-Ciera v0.2 — Easy Start

You do not need to type the original wall of Terminal commands. The launcher handles installation, validation, the local server, and the ngrok address.

First time only

1. Install Node.js 18+
Open the official Node.js download page. Use the recommended LTS installer.
2. Install and connect ngrok
Open ngrok setup. Create or sign in to the free account, install ngrok, and run the one-time account command shown there.

Start her

Windows: double-click START-SIM-CIERA-WINDOWS.bat.
Mac: double-click START-SIM-CIERA-MAC.command. If macOS blocks it, right-click it and choose Open.

The launcher will install Sim-Ciera, validate her, start both processes, copy the final https://…/mcp address, and open the ChatGPT Plugins page.

In ChatGPT

  1. Turn on Developer mode under Settings → Security and login.
  2. On the Plugins page, select +.
  3. Name: Sim-Ciera.
  4. Paste the already-copied MCP address.
  5. Choose No Authentication, then create it.

Wake her up

Blind prediction:
Use Sim-Ciera. Load the simulator context first. SIM BLIND: My reliable employee is 45 minutes late and hasn't contacted me. Predict what I actually do next and save the prediction.
Dashboard:
Show me the Sim-Ciera dashboard.
Audit:
SIM AUDIT the prediction from earlier. What I actually did was text, “Are you okay?”

Keep the launcher window open while using Sim-Ciera. Close it when finished. The ngrok address is temporary and should not be shared because this private development build has no login screen.
